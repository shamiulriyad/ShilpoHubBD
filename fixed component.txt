Task: Redesign the floating dark sidebar of the dashboard to seamlessly match the overall light, warm, and heritage-focused theme of "ShilpoHub".

Current Issues:

The floating dark pill sidebar creates an aggressive contrast with the light warm background.

Multicolored icons look visually noisy and inconsistent.

The rounded purple active state background breaks the brand identity (Terracotta / Warm Earth tones).

Design Requirements & Specs:

Layout & Positioning:

Change the floating pill layout to a Full-Height Fixed Left Sidebar (height: 100vh, position: fixed, left: 0, top: 0).

Move the ShilpoHub brand logo to the top-left inside the sidebar header.

Add a subtle right border instead of harsh drop shadows (border-right: 1px solid #E5E7EB or a light warm border #EFEBE6).

Color Palette & Theme:

Background: Crisp White (#FFFFFF) or Soft Cream Warm White (#FAFAF8).

Inactive Icons & Text: Muted Warm Neutral (#6B7280 or #786C66).

Active Item State: Terracotta / Warm Brown (#8B4513 or #A0522D) subtle background fill with matching brand text color (#8B4513).

Navigation Items:

Expand the width slightly (width: 240px or 260px) to accommodate Icon + Text Labels (e.g., Home, Heritage Management, Craft Categories, Analytics, Settings).

Use a clean Monochrome Icon Set (e.g., Lucide React or Heroicons) with uniform stroke width (1.75px or 2px).

Provide a toggle button at the bottom to collapse into an icon-only mode if needed.

Tech Stack Context (If generating code):

Tailwind CSS & React / TypeScript

Ensure clean flex/grid alignment with smooth transitions (transition-all duration-200 ease-in-out).
